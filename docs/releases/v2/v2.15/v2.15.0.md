# v2.15.0 (Minor Release)

<!-- alex-c-line-release-status-start -->
**Status**: Released
<!-- alex-c-line-release-status-end -->

<!-- alex-c-line-release-summary-start -->
This is a new minor release of the `alex-c-line` package. It introduces new features and other backwards-compatible changes that should require little to no refactoring. Please read the description of changes below.
<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Add a new global config.
  - This operates at the system level, controlling how `alex-c-line` is consumed throughout the entire system it is installed on.
- Allow the user to disable the update notifications using the new global config system.
  - This can be done using `alex-c-line config set enable-update-notifications false`.

## Additional Notes

- This is the first of a bigger planned config refactor. The plan is that global config will be used instead of private config to help control personal `alex-c-line` settings that vary from user to user, whereas the directory-level config is the existing `alex-c-line.config.js` file that determines how `alex-c-line` is configured for a specific project.
- The old `alex-c-line.private.config.js` is then expected to be deprecated and not exist anymore in the next major updatem, as by then most of the options from there should've been moved over to the global config.
