## Description of Changes

<!-- user-editable-section-start -->
- Add a few extra commands to interact with the new global config system introduced in [v2.15.0](https://github.com/alextheman231/alex-c-line/blob/main/docs/releases/v2/v2.15/v2.15.0.md).
  - `alex-c-line config get [key]` - Gets the full configuration if no key specified, otherwise it will get the key specified as the first positional argument.
  - `alex-c-line config path` - Gets the path to the raw JSON of the configuration.
  - `alex-c-line config reset` - Resets the configuration back to default settings.
