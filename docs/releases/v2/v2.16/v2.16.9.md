<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Make global config loading on startup fail-safe.
  - Otherwise we end up blocking users from the rest of the CLI if the global config is outdated.
  - This is likely to be the case whenever I add new features to the global config, and therefore it needs updating.
  - Furthermore, if the user downgrades their version of `alex-c-line` it should ideally still run as intended despite the slightly newer configuration, except for cases where it genuinely can't.
