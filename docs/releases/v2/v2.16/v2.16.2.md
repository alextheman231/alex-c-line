## Description of Changes

<!-- user-editable-section-start -->
- Add some internal filesystem helpers to make the codebase cleaner.
  - I have standardised the way we stringify JSON payloads for CLI display and file writes so that they always have line spacing and a tab width of 2.
  - I have also cleaned up the way that we check for file existence, making it easier to do this check in the command/service logic itself.
  - All of the above changes are internal changes to the codebase and should have no impact on consumers.
