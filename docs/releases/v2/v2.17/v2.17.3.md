## Description of Changes

<!-- user-editable-section-start -->
- Use `versionNumber.format()` to format the path to the release note.
  - This is expected to be more stable than just relying on `.toString()`, as I plan to eventually remove the v prefix from .toString as it feels more like a pure representation without it.
  - This should not change any existing behaviour - the release notes will still contain the v prefix. This change purely future-proofs it for now.
