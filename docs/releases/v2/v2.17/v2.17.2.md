## Description of Changes

<!-- user-editable-section-start -->
- Add a `CURRENT_CONFIG_VERSION` constant along with a test to ensure it is kept in-sync
  - Previously we were doing this in the source code itself, which was problematic because we tried reading from `src` from the built output, and so the CLI crashed because the path wouldn't exist after being built.
  - This moves the migrations directory read to a test file which doesn't get executed in production and so it can read the migrations directory just fine, and the test will then assert against a manually exported constant.
  - This does now mean that we have to manually keep track of this and there is room for this to hopefully be more optimised later, but for now at least there is a check to ensure it is kept in-sync and it won't crash the CLI.
