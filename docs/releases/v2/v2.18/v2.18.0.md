## Description of Changes

<!-- user-editable-section-start -->
- Add some `budget` commands:
  - `alex-c-line budget calculate` - Calculate your budget based on your salary, balance brought forward, and any expenses.
  - `alex-c-line budget expense add <name> <value>` - Add a constant expense to be accounted for in every calculation.
  - `alex-c-line budget expense get [name]` - Get your constant expenses, optionally specifying a key.
  - `alex-c-line budget expense remove <name>` - Remove a constant expense.

## Additional Notes

- Note that these commands require a new config version, so if you upgrade your version of `alex-c-line` and later downgrade some of your configuration settings may differ between the two versions.
- The motivation for these commands come from the fact that I am currently using a giant Excel spreadsheet to manage my monthly budget and maintaining it is a pain because the process is not always the same every time and the spreadsheet by now is very long.
- As such, I figured it'd be nice to give the budget calculations the same sort of respect I've been giving the rest of my software projects and automate them to make this easier to do. Moving the logic to this repository means they can be formatted, linted, and tested to ensure they are done consistently.
- There is room for this to be improved/expanded on in the future, so if you need a tool to help manage your finances, feel free to give this a go and let me know your thoughts.
