<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Use `Decimal` to do the budget calculations.
  - Previously it was being done with regular numbers, which was prone to things like floating point errors which could make the final calculations less accurate.
  - This changes that so that we use the Decimal class which is generally more accurate and accounts for floating point errors like that.
